# AI-Use Disclosure Draft

## Draft disclosure

An OpenAI Codex system assisted with organization of the existing project evidence, source-code review, execution and documentation of supplementary robustness scripts, literature organization, initial manuscript drafting, BibTeX formatting, and language editing. AI assistance was used in the evidence inventory, claim matrix, literature audit, robustness audit, figure/table manifest, Markdown and LaTeX drafts, reviewer-risk checklist, and reproducibility checklist.

The underlying POLIX data, original notebooks, feature matrices, trained model, project results, and web application were completed before this paper workspace was created. The AI system did not modify those original artifacts. New computations were isolated in `research_paper_ieee/supplementary_experiments` and were executed from an inspectable Python script.

The authors are responsible for independently checking every numerical value against the cited CSV or model artifact; verifying every reference against a primary or authoritative source; reviewing the official POLIX handbook and XPoSat data-use guidance; validating all scientific interpretations with an appropriate domain expert; confirming authorship, venue, funding, conflict-of-interest, and ethics requirements; and approving the final manuscript.

AI output is not cited as scientific evidence. The deterministic explanation sentences produced by the deployed Flask application are template-based Python strings and were not generated by an LLM.
